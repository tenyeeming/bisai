# AcuNavi — AI 穴道導航系統（展示版）

用手機或電腦的鏡頭，**即時把穴道標在你自己的手上**，再引導你按壓。
資服競賽（InnoServe 第 31 屆）展示版。

## 👉 直接打開

### **https://tenyeeming.github.io/bisai/**

用 **Chrome 或 Edge** 開，會跳出「要求使用攝影機」→ **請按允許**（不允許的話定位那一步不會動）。
畫面是做成手機比例的，電腦上會看到一個手機外框，那是刻意的。

> 攝影機影像**完全在你的裝置上處理，不會上傳**。這個網站沒有後端、沒有資料庫，關掉分頁就什麼都不留。

## 操作流程（照這個順序點就好）

```
症狀 ──▶ 選穴 ──▶ 認穴 ──▶ 定位 ──▶ 按摩 ──▶ 完成
 13 種    26 穴    位置說明   即時鏡頭   雙手確認   收集小人
                   安全警語   圓盤標示   左右各一輪
```

| 步驟 | 畫面上做什麼 | 想看什麼 |
|---|---|---|
| **1. 首頁** | 選一個症狀（例：頭痛、肩頸痠痛） | 13 種症狀，含 2 個急症 |
| **2. 選穴** | 系統推薦對應穴道，勾選要按的 | 只推薦**已實作定位公式**的 20 個穴，沒做的會標「準備中」且不可勾選 |
| **3. 認穴** | 文字說明這個穴在哪、注意事項 | 每個穴附**安全警語**（孕婦、血管神經位置） |
| **4. 定位** ⭐ | **鏡頭打開，手伸出來**，紅點會跟著手跑 | **這是核心**。看下面〈定位這一步要看什麼〉 |
| **5. 按摩** | 跟著計時器按壓，左右手各一輪 | 雙手都要做完才算完成 |
| **6. 完成** | 該穴道的「小人」升級 | 收集養成，鼓勵持續使用 |

底部四個分頁：**首頁**（上面這條流程）／**圖冊**（26 穴收集進度）／**設定**（語言等）／**個人**（連續天數統計）。

## ⭐ 定位這一步要看什麼

這是整個系統的技術核心，其他都是外殼。

| 看什麼 | 說明 |
|---|---|
| **紅點會跟著手動** | 手轉、手移、離遠離近都會跟，因為每一幀都重新用手的比例（同身寸）換算，不是固定像素 |
| **圓盤會變扁** | 手轉到側面時，穴道的圓盤會壓扁 → **這是「我現在沒把握」的即時信心度**，不是裝飾。手轉正圓盤就回圓 |
| **手太斜會擋住** | 傾角超過 25° 會擋下不給定位，寧可不給也不給錯的 |
| **手心手背都能定位** | 26 穴裡有 10 個側緣穴，正反面都算得出來 |

**試試看：** 把手慢慢轉到側面，看圓盤怎麼變 —— 這是我們跟一般「貼張圖上去」的做法最不一樣的地方。

### 臉部穴道（選穴頁的「臉部」分頁）

第二條線，**目前只做了 4 個穴（睛明／承泣／四白／巨髎）**，其餘 19 個列得出來但標「準備中」。
定位頁會把**每一條公式的參數來源**印在畫面上（哪些是照 WHO 定義寫的、哪些是從標注資料擬合的），沒有隱藏。

誠實列出來，畫面上也是這樣標的：

|---|---|

**還沒做的：**
- 手心的穴道（勞宮、魚際等）定位公式還沒寫 —— 缺手心的標注資料
- 臉部側面的穴道（太陽、頰車等）—— 側面偵測本來就是這類方法的已知難點
- 臉部只驗過 1 個人，數字還不能當準確度看

## 打不開的話

| 狀況 | 處理 |
|---|---|
| 沒跳出攝影機授權 | 網址列左邊的鎖頭 → 網站設定 → 攝影機 → 允許 → 重新整理 |
| 第一次進定位頁畫面黑黑的 | AI 模型要從網路下載（臉部那顆約 10MB），等一下就好，臉部定位頁下方有提示 |
| Safari 上怪怪的 | 請改用 **Chrome 或 Edge** |
| 完全開不起來 | 這份也可以下載整包、雙擊 `acunavi-ideal.html` 離線開 |

## 這包裡面有什麼

```
acunavi-ideal.html   ← 網站本體（雙擊也能離線開）
js/                  ← 定位公式（acu-math 手部 / face-math 臉部）與鏡頭處理
pages/               ← 一頁一個檔，檔名的數字就是流程順序
assets/              ← 穴道參考圖、收集用的小人
tests/               ← 自動測試（含拿真實標注驗證公式的那支）
開發說明.md          ← 給工程用的：架構、要改哪個檔、已知風險
```

技術：純前端 HTML/CSS/JS，手部用 MediaPipe Hands（21 點）、臉部用 MediaPipe FaceMesh（478 點），
穴道位置由專案自己的公式算出來（`js/acu-math.js` / `js/face-math.js`）。沒有後端。
