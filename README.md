# AcuNavi — AI 穴道導航系統（展示版）

用手機或電腦的鏡頭，**即時把穴道標在你自己的手、臉、前臂上**，再引導你按壓。
資服競賽（InnoServe 第 31 屆）展示版。

## 👉 直接打開

### **https://tenyeeming.github.io/bisai/**

用 **Chrome 或 Edge** 開，會跳出「要求使用攝影機」→ **請按允許**（不允許的話定位那一步不會動）。
手機、平板直接用；電腦寬螢幕會改成左邊側欄導覽、右邊一次一頁。

> 攝影機影像**完全在你的裝置上處理，不會上傳**。這個網站沒有後端、沒有資料庫。

---

## 操作流程（照這個順序點就好）

```
症狀 ──▶ 選穴 ──▶ 認穴 ──▶ 定位 ──▶ 按摩 ──▶ 完成
 20 種    手／手肘／臉   位置說明   即時鏡頭   計時按壓   小人慶祝
                       安全警語   綠點標示   左右各一輪
```

| 步驟 | 畫面上做什麼 | 想看什麼 |
|---|---|---|
| **1. 首頁** | 選一個或幾個症狀（例：頭痛、肩頸痠痛） | 20 種症狀 |
| **2. 選穴** | 系統推薦對應穴道，分「手部／手肘／臉部」三格，勾選要按的 | 選了多個症狀時，上方會標出哪個症狀還沒有勾到穴道 |
| **3. 認穴** | 參考圖＋文字說明這個穴在哪、注意事項 | 每個穴附**安全警語** |
| **4. 定位** ⭐ | **鏡頭打開，手（或臉）伸出來**，點會跟著跑 | **這是核心**，看下面〈定位這一步要看什麼〉 |
| **5. 按摩** | 跟著計時器按壓，左右各一輪 | 進頁倒數後自動開始 |
| **6. 完成** | 這個穴道的「小人」跳出來慶祝 | 網頁版**不存紀錄**；養成系統在 App |

底部（電腦版在左側欄）三個分頁：**首頁**（上面這條流程）／**圖冊**（每個穴道的參考圖與說明）／**設定**（語言、顯示、療程節奏、提醒）。

---

## ⭐ 定位這一步要看什麼

| 看什麼 | 說明 |
|---|---|
| **點會跟著手動** | 手轉、手移、離遠離近都會跟，因為每一幀都重新用手的比例（同身寸）換算，不是固定像素 |
| **太斜會擋住** | 每個穴有自己的角度上限，超過就不給定位，寧可不給也不給錯的 |
| **臉部看角度** | 臉轉太多會先藏起穴點，轉回正面再出現 |

## 打不開的話

| 狀況 | 處理 |
|---|---|
| 沒跳出攝影機授權 | 網址列左邊的鎖頭 → 網站設定 → 攝影機 → 允許 → 重新整理 |
| 第一次進定位頁畫面黑黑的 | AI 模型要從網路下載，等一下就好 |
| Safari 上怪怪的 | 請改用 **Chrome 或 Edge** |
| 完全開不起來 | 也可以下載整包、雙擊 `acunavi-ideal.html` 離線開 |

## 這包裡面有什麼

```
acunavi-ideal.html   ← 網站本體（雙擊也能開）
js/                  ← 定位公式（acu-math 手部 / face-math 臉部 / forearm-vision 前臂）與鏡頭處理
pages/               ← 一頁一個檔，檔名的數字就是流程順序
css/                 ← 版面（desktop.css 是電腦寬螢幕版）
assets/              ← 穴道參考圖、完成時慶祝的小人
tests/               ← 自動測試（含拿真實標注驗證公式的那支）
開發說明.md          ← 給工程用的：架構、要改哪個檔、已知風險
```

技術：純前端 HTML/CSS/JS；手部 MediaPipe Hands（21 點）、臉部 MediaPipe FaceMesh（478 點）、前臂另用 MediaPipe Pose；
穴道位置由專案自己的公式算出來。沒有後端。
